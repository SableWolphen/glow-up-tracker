# Project conventions

- **Never use "claude" in branch names.** Use plain descriptive branch names
  (e.g. `fix-widget-clipping`, not `claude/fix-widget-clipping`) so merge
  commit messages on `main` never mention it either.
- **Never add a Claude/AI co-author line to commits.** Commits in this repo
  are attributed to the repo owner, not to the assistant that wrote them.
- Note: PR descriptions and GitHub comments still require a "Generated by
  Claude Code" attribution footer — this is a fixed requirement of the
  Claude Code environment, not something this file can turn off.
- **When testing real push notifications end-to-end, use
  `johnston.alexander.k@gmail.com`** (Sable's own account) rather than the
  Cozy/Guardian Play Store review accounts — it's the one with a real device
  that can actually confirm delivery, not just the server-side computation.
